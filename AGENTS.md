# Agent guidelines

Follow these rules when changing this project.

## Minimalism

Keep the code simple. Follow the KISS principle.

## Single Responsibility Principle

Each function or module should have one job.

## Comments

Write comments in English at an intermediate level.

- Explain what happens and why it happens.
- Comment every logical block so the code can be understood by reading
  the comments alone.
- Use documentation comments.

## Line length

Wrap lines at 80 characters. URLs and Markdown tables
may exceed this limit.

## Commits

Use the imperative mood in the commit message.

- Title: up to 50 characters. Hard limit is 72.
- Blank line: required between the title and the body.
- Body: wrap each line at 72 characters. Use a body only when more than one
  logical change is made, or when the change is not intuitive and needs
  extra explanation.
